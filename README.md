Smart Sensor Monitoring Dashboard

Developed by: Ashish Kumar Bhambhi
Branch: Electronics and Communication Engineering (ECE)

Project Overview

The Smart Sensor Monitoring Dashboard is a web-based project designed to demonstrate sensor data monitoring through a simple and interactive dashboard.

Features

- Displays temperature, humidity, and voltage readings.
- Refresh Readings button to update displayed values.
- Simple and user-friendly interface.
- Accessible through a web browser.

Technologies Used

- HTML
- CSS
- JavaScript
- GitHub Pages

Live Demo

https://ashishkumarbhambhi-cmd.github.io/smart-sensor-monitoring-dashboard/

Working Principle

The dashboard displays sample sensor readings and allows users to refresh the displayed values. The current version is a simulation and does not claim to receive data from physical sensors.

Future Improvements

- Integration with real sensors.
- ESP32 or Arduino connectivity.
- Real-time data visualization.
- Sensor status alerts.
